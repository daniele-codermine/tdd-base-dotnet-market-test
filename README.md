## Inizializzazione del Progetto (git)

Una volta scaricato questo progetto, lanciare:
`dotnet build`

Questi comandi installano i pacchetti necessari. 

## Configurazione
Aggiungere nel file `appsettings.json` nel progetto MarketServiceTest il path alla cartella che contiene i file dei prodotti `products.json`, esempio `C:\\Users\\Daniele Arrighi\\dotnet-market-test\\MarketService\\Data` assicurandosi di usare un doppio backslash \ per il path. Questo permette di caricare correttamente i file dei prodotti e può essere usata come base per caricare altri dati.
